# SOCOM: U.S. Navy SEALs — русификатор v3.00

Русификатор для **PS2 USA v3.00, SCUS-97134**. Текущий выпуск — **ru-1.3**.
Оригинальная английская озвучка сохранена. Другие регионы, ревизии и уже
изменённые образы не поддерживаются.

Репозиторий не содержит ISO игры. Для установки пользователь предоставляет
собственный чистый английский образ.

## Установка

Требуется Python 3.11 или новее.

1. Скачайте или клонируйте репозиторий.
2. Перетащите чистый ISO на корневой `install.cmd`.
3. Рядом с оригиналом появится новый файл с окончанием `.ru.iso`.

Можно запустить установку вручную:

```powershell
python -B tools/project.py build --input ".\SOCOM-original.iso" --output ".\SOCOM-ru.iso"
```

Установщик проверяет размер и SHA-256 исходного образа и никогда не
перезаписывает существующий файл.

Исходный ISO должен иметь размер `3 493 593 088` байт и SHA-256:

```text
b1730e5efe4dc87d033f33c43137e9e7e2114c77f3a28bd1db2d005419a027bd
```

## О русификаторе

Проект содержит русский текстовый перевод игры и собирает новый образ напрямую
из ресурсов и чистого английского ISO. Оригинальная английская озвучка не заменяется.

Проверены структура всех 678 файлов итогового образа, 95 таблиц анимаций и
сохранность 70 файлов английской озвучки, видео и распознавания. Это не означает
прохождение всей кампании и проверку каждого игрового окна.

## Состав репозитория

| Путь | Назначение |
|---|---|
| `install.cmd` | запуск прямой сборки русского ISO из корня репозитория |
| `resources/files/` | 43 актуальных игровых ресурса русификации |
| `resources/manifest.json` | размеры и SHA-256 ресурсов |
| `sources/` | редактируемые снимки RDR, словари и данные EXE |
| `tools/` | аудит, сборка, упаковка и безопасная сериализация |
| `reference/` | инвентарь чистого ISO и технические контрольные данные |
| `docs/` | документация для разработки и описание форматов |
| `project.json` | версия, контрольные суммы и относительные пути проекта |

ISO, отчёты проверок, временные индексы и кэши исключены через
`.gitignore`.

## Проверка репозитория

Проверки без ISO и без создания файлов:

```powershell
python -B tools/project.py status
python -B tools/project.py audit
python -B tools/verify_distribution.py
```

Полная проверка с собственным чистым ISO:

```powershell
python -B tools/project.py verify --input ".\SOCOM-original.iso"
python -B tools/verify_distribution.py --input ".\SOCOM-original.iso" --full-install
```

Отдельный патч, архив и папка выпуска не создаются: установка запускается
непосредственно из корня репозитория и использует `resources/files/`. Инструкции по развитию перевода — в
[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md), сведения о форматах — в
[docs/TECHNICAL.md](docs/TECHNICAL.md). Правила для автоматизированных агентов
вынесены в [AGENTS.md](AGENTS.md).
