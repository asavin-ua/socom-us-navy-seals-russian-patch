# Материалы перевода

`rdr/` — экспорт 291 раздела из текущих ресурсов v3.00, `index.json` описывает каждый файл.
JSON хранит точное дерево с игровыми строками, представленными через Latin-1.
Не заменяйте их непосредственно кириллицей: используйте `tools/text_encoding.py`.
В текущем выпуске все 291 раздел сохранены в JSON, BIN-файлов нет.
Экспортёр также умеет сохранять BIN для разделов с внешними указателями, если такие встретятся;
их нельзя безопасно декодировать в обычное дерево.

`compiled/` создаётся локально экспортёром и содержит справочные записи имён
текущих ZANIM/ZWEAPON, включая служебные значения. Каталог восстанавливается из
`resources/files/` и поэтому не хранится в Git.
`executable/` — проверенные видимые строки текущего EXE и их игровые байты.
`dictionaries/` — читаемые русские формулировки и унаследованный словарь перевода.
Старые адреса/ёмкости строк из прежних словарей удалены. Словари могут содержать
ранние варианты формулировок: перед изменением сверяйтесь с текущими ресурсами.

Первоисточник готового выпуска — `resources/files/`. Он содержит весь перевод,
включая растры шрифтов и изображений, а не только текст, добавленный в последних правках.
Экспорт выполняется `python -B tools/resources.py export`; подготовка правок описана в
`docs/DEVELOPMENT.md`.
